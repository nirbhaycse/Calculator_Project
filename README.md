# Simple Calculator

A responsive calculator built with **HTML, CSS, and vanilla JavaScript**. It supports basic arithmetic with operator precedence and can be used with the on-screen keypad or keyboard.

**Repository:** https://github.com/nirbhaycse/Calculator_Project

## Features

- Addition, subtraction, multiplication, and division.
- Decimal numbers and repeated-digit input (`00`).
- Clear-all and delete-last-character controls.
- Keyboard support for numbers, operators, Enter, Backspace, and Escape.
- Arithmetic parsing without JavaScript's `eval()`.
- Responsive layout for different screen sizes.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/nirbhaycse/Calculator_Project.git
   cd Calculator_Project
   ```

2. Open `index.html` in your browser. No build step or package installation is required.

## Project Structure

```text
.
├── index.html  # Calculator markup and keypad
├── style.css   # Layout and visual styling
├── script.js   # Input handling and arithmetic parser
└── README.md   # Project documentation
```

## Learning Goals

This project demonstrates DOM event handling, form controls, CSS layout, input validation, and parsing basic arithmetic expressions.

## Limitations

- This is a basic calculator, not a scientific calculator.
- Parentheses and advanced mathematical functions are not supported.
- Floating-point arithmetic has the same precision limitations as JavaScript numbers.
